# SilentTrack - نظام ALPR للشرطة السرية

نظام ALPR ميداني يعمل محلياً على جهاز داخل السيارة (أو كمحاكاة محلية على حاسوب) يلتقط لوحات السيارات من البث المباشر للكاميرا، يقرأ النصوص عبر OCR، ويطابقها مع قاعدة بيانات محلية تحتوي على لوحات مبلغ عنها (مسروقة/مشتبه بها). إذا وُجد تطابق، يظهر تنبيه مرئي/صوتي وضابط العمليات يملك خيارات: "تمت المعالجة" أو "استدعاء دعم". يعمل النظام أوفلاين، قابل للتشغيل لاحقًا على جهاز مثل Raspberry Pi مع تعديل طفيف.

## المتطلبات

### متطلبات النظام
- **Python 3.10.6** (مطلوب)
- **Windows 10/11** (للاختبار المحلي)
- **كاميرا USB** (اختياري للوضع الحقيقي)
- **4 GB RAM** كحد أدنى
- **2 GB مساحة تخزين** متاحة

### متطلبات البرمجية
- **Tesseract OCR** - يجب تثبيته على النظام
- **OpenCV** - للتعامل مع الصور والفيديو
- **Flask** - لخادم الويب
- **SQLite** - قاعدة البيانات المحلية

## التثبيت

### 1. تثبيت Tesseract OCR

#### على Windows:
1. قم بتحميل Tesseract من الموقع الرسمي: https://github.com/UB-Mannheim/tesseract/wiki
2. قم بتثبيته في المسار الافتراضي: `C:\Program Files\Tesseract-OCR\`
3. تأكد من وجود الملف: `C:\Program Files\Tesseract-OCR\tesseract.exe`

#### على Raspberry Pi:
```bash
sudo apt update
sudo apt install tesseract-ocr
```

### 2. تثبيت المكتبات

```bash
# الانتقال إلى مجلد المشروع
cd "C:\..\VSCode\Projects\SilentTrack"

# إنشاء بيئة افتراضية (اختياري)
python -m venv .venv

# تفعيل البيئة الافتراضية
# على Windows:
.venv\Scripts\activate
# على Linux/Mac:
source .venv/bin/activate

# تثبيت المكتبات
pip install -r requirements.txt
```

### 3. إعداد مسار Tesseract

إذا كان Tesseract مثبت في مسار مختلف، قم بتعديل الملف `config.py`:

```python
TESSERACT_CMD = r"المسار_إلى_tesseract.exe"
```

## التشغيل

### 1. تشغيل النظام

```bash
# من مجلد المشروع
python app.py
```

أو باستخدام Flask:

```bash
flask run --host=127.0.0.1 --port=5000
```

### 2. الوصول للنظام

افتح المتصفح وانتقل إلى: `http://127.0.0.1:5000`

### 3. تسجيل الدخول

- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin123`

## استخدام النظام

### 1. البث المباشر

- **وضع المحاكاة:** يعرض فيديو تجريبي مع لوحات وهمية
- **وضع الكاميرا:** يستخدم الكاميرا الحقيقية المتصلة

### 2. تبديل الأوضاع

1. انتقل إلى صفحة "الإعدادات"
2. اختر "إعدادات الكاميرا"
3. غير "وضع التشغيل" بين "محاكاة" و "كاميرا حقيقية"
4. احفظ الإعدادات

### 3. إدارة المركبات المبلغ عنها

1. انتقل إلى "الإعدادات" > "قاعدة البيانات"
2. في قسم "إدارة المركبات المبلغ عنها"
3. أضف لوحات جديدة أو احذف الموجودة

### 4. عرض السجل

انتقل إلى صفحة "السجل" لعرض جميع الاكتشافات والتنبيهات.

## ربط الهاردوير

### 1. الكاميرا

#### كاميرا USB:
```python
# في config.py
CAMERA_INDEX = 0  # 0 للكاميرا الافتراضية
```

#### كاميرا شبكية (RTSP):
```python
# في config.py
RTSP_URL = "rtsp://username:password@ip:554/stream"
```

#### كاميرا Raspberry Pi (CSI):
```python
# على Raspberry Pi
CAMERA_INDEX = 0  # بعد تمكين كاميرا Pi
```

### 2. حساسات المسافة (اختياري)

#### حساس ToF (VL53L0X) على Raspberry Pi:
```bash
# تثبيت المكتبة
pip install adafruit-circuitpython-vl53l0x
```

```python
# في الكود
import board
import adafruit_vl53l0x

i2c = board.I2C()
sensor = adafruit_vl53l0x.VL53L0X(i2c)
distance = sensor.range
```

#### حساس Ultrasonic عبر Arduino:
```python
# استخدام pyserial
import serial

ser = serial.Serial('COM3', 9600)  # Windows
# ser = serial.Serial('/dev/ttyUSB0', 9600)  # Linux
distance = ser.readline().decode().strip()
```

### 3. النشر على Raspberry Pi

#### خطوات النشر:
1. **تثبيت Python 3.10:**
```bash
sudo apt update
sudo apt install python3.10 python3.10-venv python3-pip
```

2. **تثبيت Tesseract:**
```bash
sudo apt install tesseract-ocr
```

3. **نسخ المشروع:**
```bash
scp -r SilentTrack/ pi@raspberry-pi-ip:/home/pi/
```

4. **تثبيت المكتبات:**
```bash
cd /home/pi/SilentTrack
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

5. **تعديل الإعدادات:**
```python
# في config.py
TESSERACT_CMD = "/usr/bin/tesseract"
CAMERA_INDEX = 0  # للكاميرا المحلية
```

6. **تشغيل النظام:**
```bash
python3 app.py
```

### 4. التوصيلات الكهربائية

#### Raspberry Pi:
- **مصدر طاقة:** 5V/3A عبر USB-C
- **كاميرا:** CSI أو USB
- **حساسات:** I2C أو Serial

#### حماية الطاقة:
- **محول 12V إلى 5V** للسيارة
- **مكثف كبير** لتثبيت الجهد
- **صمام حماية** من الجهد العكسي

## استكشاف الأخطاء

### مشاكل شائعة:

#### 1. خطأ Tesseract:
```
TesseractNotFoundError: tesseract is not installed
```
**الحل:** تأكد من تثبيت Tesseract وتعديل المسار في `config.py`

#### 2. خطأ الكاميرا:
```
Camera not found
```
**الحل:** تحقق من اتصال الكاميرا وفهرسها في `config.py`

#### 3. خطأ في المكتبات:
```
ModuleNotFoundError
```
**الحل:** تأكد من تثبيت جميع المكتبات: `pip install -r requirements.txt`

#### 4. بطء الأداء:
**الحلول:**
- تقليل دقة الفيديو
- تقليل معدل الإطارات
- إغلاق البرامج الأخرى

### سجلات النظام:
- تحقق من وحدة التحكم (Console) للأخطاء
- راجع ملفات السجل في النظام
- استخدم وضع المحاكاة للاختبار
